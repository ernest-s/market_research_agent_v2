# JWT verification
Auth0 ID tokens (auth0_id_token cookie) are verified using RS256 signature validation
via the shared utility src/lib/verifyIdToken.ts. It fetches Auth0's public keys from
/.well-known/jwks.json (keys are cached in memory) and validates the signature,
audience (AUTH0_CLIENT_ID), and issuer (AUTH0_ISSUER_BASE_URL).

Use verifyIdToken() instead of jwt.decode() anywhere the auth0_id_token cookie is read.
Never trust the token's payload without calling verifyIdToken() first.

Affected routes: api/auth/callback, api/auth/bootstrap,
api/auth/session/override, (app)/auth/change-password
